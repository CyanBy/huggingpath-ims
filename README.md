# HuggingPath
HuggingPath 是病理影像 + AI 分析前端原型。

Vue 3 + TypeScript + Vite + Tailwind，hash 路由，开发端口 3000。无后端、无真实推理或瓦片服务，数据存在 localStorage / sessionStorage。

开发时用 Vite，端口 3000。
演示账号 demo / demo123

## 更新说明

### 2026-09-09
- 统一模型中心、WSI、Case 与研究项目的分析启动流程：进入工作台前完成模型配置，确认后立即创建并启动分析；批量对象支持全部使用同一模型，也支持按切片分别指定模型。
- 扩大分析模型配置弹窗和文字、按钮尺寸，统一配置模式默认展开 Case 与关联切片，按切片模式提供清晰的兼容数量和逐张模型选择。
- 传输能力拆分为“顶部快速预览 + 独立传输队列页面”：导航图标展示进行中数量、异常或完成状态，快速预览保留最近任务，并可跳转查看全部记录；工作台下拉菜单新增“传输队列”入口。
- 传输队列改为紧凑表格布局，按文件、取材信息、Case、状态与进度、创建/结束时间和操作分列展示，支持状态筛选、搜索、取消、重试、移除及清理已完成记录。
- WSI 上传改为乐观占位：任务创建后立即出现在 WSI 表格，依次展示等待上传、上传进度和文件处理状态；完成后占位行原位转为正式 WSI，失败或取消时保留恢复操作。
- WSI 与 Case 新增统一的“查看分析”入口，默认打开最近一次已完成结果；工作台右侧新增可展开的分析记录时间轴，可按对象查看历史模型、状态、时间和任务编号并切换过往结果。
- 分析次数统一按已完成的分析任务统计，不再把同一次任务内的多个模型运行误计为多次分析；从 Case 进入历史分析时继续展示可收起的 Case 临床上下文。

- 创建分析任务的 Case 列表同步展示患者、诊断、收样、送检及 WSI 数量，并提供行内详情和原地添加 WSI；从 Case 详情发起分析时会自动定位并选中当前 Case。
- Case 分析工作台新增默认展开、可收起的 Case 上下文卡片，放大关键信息字号，并提供完整详情跳转；导航搜索框及公共卡片、弱按钮的边框颜色同步修正为系统主题样式。

### 2026-09-07

- TME 定量页按 Demo 结构重做：顶部集中展示分类数、总计数和分析倍率，下方依次提供全局标注、细胞核分类和区域分类，不再重复展示原组织构成与细胞核构成摘要。
- 标注控制补齐全局、分组和单分类三级交互：支持整体显示/隐藏、全局透明度、细胞核与区域独立显示及透明度、每个分类的显示开关和透明度；全局开关不会覆盖分类自身的选择状态。
- 细胞核 10 类和区域 9 类均展示颜色、名称、数量及占比条，长名称自动省略；所有开关和滑杆会实时驱动中央切片上的细胞核与区域图层。
- 中央工作区删除重复的 `WSI 浏览 / 批次对比` 模式栏和批次特征表，完整特征表、统计热力图及空间热力图统一保留在特征分析弹窗中。
- TME 特征相关界面清理 `SPARK`、`FULL` 和“全量”强调词，统一使用“特征分析”“951 维特征”“标准计算”等中性描述；原 `SPARK` 分类同步改名为“综合特征”。
- 全局按钮层级完成回归：普通查看、返回、关闭和取消操作使用中性弱按钮，推理与次级执行操作使用系统紫色弱强调；Case 与 WSI 的列表勾选均改为页面级临时状态，离开页面后自动清空。

- SPARK 特征分析由快速模式调整为全量模式，统一显示 `FULL 951`、951 个特征与 936 个有效特征；右侧概览和完整分析弹窗共享同一份特征目录、数值、分类、细胞数、ROI、耗时等摘要数据。
- 新增完整 SPARK 特征分析弹窗：支持 951 项特征的搜索、28 类分类筛选、仅热门、默认热门、全选和清空，并提供分析进度、清理结果重跑及多切片切换。
- 完整 SPARK 结果支持“热力图 + 统计”“完整特征表”和“空间热力图”三种查看方式；可查看跨切片归一化热力图、均值/标准差/中位数/极值统计，以及按空间特征和切片切换的示例叠加结果。
- TME 相关操作统一移入工作台右侧结果区，集中提供细胞核、特征热力图、标注和 SPARK 特征分析入口；删除中央阅片工具栏中的重复入口和右侧重复的完整分析按钮，未启用状态不再使用类似选中的描边。
- 新增 TME 标注图层演示交互：支持全局显示/隐藏、透明度、框选 ROI 定量，以及细胞核和组织区域两组标签的分层开关、颜色调整和切片叠加；工具配色与工作台现有紫色系统保持一致。
- 优化 TME 全量分析弹窗和右侧特征列表的字号、间距、表格滚动与长名称显示，提高 951 维特征和统计信息在高密度界面中的可读性。
- 创建分析任务页的“上传 WSI”改为系统紫色弱强调样式，上传弹窗的批量选择、应用和取消操作统一控件高度、圆角、颜色和键盘聚焦状态。
- WSI 勾选改为页面级临时状态，不再通过 sessionStorage 跨页面恢复；进入上传页、Case 页面或完成导入后返回，旧切片不会再次自动选中，相关返回提示同步修正。

### 2026-09-01
- 模型目录收敛为 `CellViT V2` 和 `TME Analyzer` 两个可运行模型，模型中心、首页、关于页、平台模型管理、机构工作台模型及后台 GPU 任务名称同步使用同一份目录数据。
- 统一模型的展示信息与工作台能力配置：模型目录同时维护模型 ID、运行说明和支持染色，工作台不再单独硬编码另一组模型，后续增删或改名只需维护一处。
- 首页和模型中心改为适合两个模型的双列布局，模型数量、社区统计和模型性能排行同步为当前目录内容。
- 待分析的旧任务增加模型兼容迁移：旧 `mod-cellvit` 自动映射为 `ai4path/cellvit-v2`，已下架模型不再出现在新任务配置中；正在运行或已完成的历史任务仍保留原模型记录。
- 工作台左侧 WSI 卡片继续显示总分析进度，并按模型数量显示“未配置模型”、单个模型名称或“N 个模型”；选择多个模型时，鼠标悬停或键盘聚焦进度区域可查看每个模型的状态和进度，浮层锚定在卡片内侧，不再占用卡片高度或遮挡中央阅片区。
- 工作台右侧分析结果支持按模型独立切换：`CellViT V2` 显示检测概览、细胞分类和独立报告，`TME Analyzer` 显示 TME 定量、特征分析和独立报告；暂不生成跨模型聚合结果。
- 模型切换会同步重置当前结果页签和特征热力图，报告生成状态按模型隔离，避免不同模型之间复用错误的结果状态。
- 分析任务改用稳定、可检索的 `AT-日期-时间-短码` 任务编号作为主标识，已有本地任务会根据原 ID 和创建时间自动兼容；任务列表列名、搜索提示和工作台标题同步使用任务编号，不再拿切片号、Case 编号或项目名称代替任务名称。
- 修正纯 WSI 任务的范围语义：从 WSI 对象创建的任务即使切片绑定了 Case，也只显示“单张/批量 WSI 分析”和平铺切片列表，不再提升为 Case 范围；从 Case 或研究项目入口创建的任务继续保留项目、Case、切片层级，底层 WSI 与 Case 的数据关联不受影响。
- 任务列表继续通过任务编号悬停查看多对象分析范围；进入工作台后不再重复显示任务范围浮层，左侧已经通过 WSI 卡片和配置数量直接呈现当前任务内容。
- 工作台 WSI 卡片的长文件名改为中间省略，固定保留末尾序号、染色标记和扩展名；悬停或键盘聚焦即时显示完整名称，点击名称可复制去掉 `.svs`、`.sdpc` 等扩展名后的切片名称，并显示复制成功反馈。
